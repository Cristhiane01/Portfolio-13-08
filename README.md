# Portfólio Cristhiane Ferreira

Esta é a versão pronta para publicar no GitHub Pages. Ela contém apenas os arquivos estáticos necessários: `index.html`, `assets/`, `certificados/` e `.nojekyll`.

## Publicar

1. Crie um repositório público no GitHub.
2. Envie o conteúdo desta pasta para a branch `main`.
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione `main` e a pasta `/ (root)` e clique em **Save**.
6. Aguarde o GitHub gerar o endereço do site.

Não é necessário instalar Node.js, pnpm ou qualquer dependência para publicar esta versão. O build já foi gerado e os comprovantes dos cursos estão incluídos em `certificados/`.
